🎵 VerseFlow

VerseFlow is a powerful, browser-based lyric video creator that allows content creators to generate professional-grade visualizers directly from the web. With support for 4K export, custom animations, and multiple aspect ratios, it bridges the gap between complex video editing software and quick social media content creation.

✨ Features
🎬 Professional Video Production
High-Resolution Export: Support for 4K (3840×2160), 1080p, and 720p rendering.

Multi-Platform Aspect Ratios:

16:9 (YouTube/Widescreen)

9:16 (Shorts/Reels/TikTok)

1:1 (Square Posts)

4:5 (Instagram Feed)

Variable Frame Rates: Export at 24fps (Cinematic), 30fps, or 60fps (Smooth).

🎨 Advanced Customization
Dynamic Text Animations: Choose from Typewriter, Fade In, Slide Up, Bounce, and Glow Pulse effects.

Rich Typography: Customize Font Family (Poppins, Inter, Bebas Neue), Size, Color, Glow, and Shadow.

Background Engine: Use custom Image Uploads, Dynamic Gradients, or Solid Colors with adjustable blur and overlay opacity.

🛠️ Workflow Tools
Bulk Lyrics Import: Paste entire song lyrics and automatically sync them line-by-line.

Keyboard Shortcuts:

Space: Play/Pause

Ctrl+S: Save Project

Ctrl+Shift+S: Export Video

Ctrl+V: Paste Lyrics

Project Management: Save and load projects locally to continue editing later.

Frontend: HTML5, CSS3, Vanilla JavaScript (ES6+)

Rendering Engine: HTML5 Canvas API

Hosting: Netlify

💻 Installation & Usage
Since VerseFlow is a static web application, you can run it locally without complex build steps.

Clone the Repository

bash
git clone https://github.com/Daivik1520/teminal_tunes.git
cd teminal_tunes
Run Locally

Simply open index.html in any modern web browser.

Optional: For a better development experience, use a live server extension (like Live Server in VS Code) to serve the files.
